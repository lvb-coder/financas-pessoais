# Minhas Finanças

App pessoal de organização financeira (Fase 1: consolidação e categorização de gastos).

## Rodar localmente (opcional, exige Node.js instalado)
```
npm install
npm run dev
```

## Colocar no ar (recomendado, sem precisar instalar nada no computador)
Veja o passo a passo completo na conversa com o Claude. Resumo:
1. Suba esta pasta para um repositório no GitHub (upload pela web, sem precisar de comandos git).
2. Importe o repositório na Vercel (vercel.com).
3. Configure as variáveis de ambiente VITE_SUPABASE_URL e VITE_SUPABASE_ANON_KEY (os valores já estão no arquivo `.env` desta pasta).
4. Deploy. Depois, abra o link gerado no celular e use "Adicionar à tela inicial" para instalar como app.
